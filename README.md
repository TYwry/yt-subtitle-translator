# YT 字幕翻譯

替外國 YouTube 影片自動加上翻譯字幕（預設繁體中文，上下兩行同時顯示中文與原文）：影片有字幕就直接翻譯，沒有字幕就由你電腦上的小程式聽聲音、辨識成文字再翻譯。

## ⬇️ 下載

**[按這裡下載最新版（yt-subtitle-translator.zip）](../../releases/latest/download/yt-subtitle-translator.zip)**

下載後在檔案上按右鍵 →「解壓縮全部」，然後照下面的「使用步驟」做。

## 功能

- **自動翻譯 YouTube 字幕**：影片有字幕（CC）時，抓下來交給 AI 翻成自然、口語的中文。
- **沒有字幕也能看**：由電腦上的「本機助手」把影片聲音辨識成文字（有 NVIDIA 顯示卡會快很多），再翻譯。開頭幾句會先出現，不用等整部做完。
- **雙語字幕**：中文大字、原文小字，可以對照著看。
- **看過的影片會記住**：同一部影片再看一次，字幕直接出現。
- **可選翻譯語言**：除了繁體中文，也能翻成簡體中文、英文、西班牙文、法文、俄文等全球最多人使用的語言。
- **字幕列表**：影片右側列出整部影片的字幕，像音樂 App 的歌詞一樣跟著播放捲動、目前這句會標亮；點任何一句就跳到那個時間，也能一鍵複製全部字幕或單句。切換翻譯語言後，列表會跟著換成新語言。
- **大綱摘要**：在右側面板的「大綱」分頁按「產生大綱」，本機助手會用你的 Groq 金鑰把影片整理成幾個段落（時間、小標題、重點），點時間就跳過去。整理好會存在電腦裡，下次直接顯示。
- **播放器上的「中」按鈕**：一鍵開關字幕。
- **本機助手沒開時會提醒**，按「立即開啟」就能在背景啟動。

## 使用前準備

| 項目 | 說明 |
|---|---|
| 電腦 | Windows 10 或 11 |
| 瀏覽器 | Google Chrome（Microsoft Edge 也可以） |
| Python | 3.10 以上，建議 3.12（下面步驟 1 會教你安裝） |
| 硬碟空間 | 約 3～4 GB（程式元件與語音模型） |
| 顯示卡 | 建議有 NVIDIA 顯示卡；沒有也能用，只是辨識聲音比較慢 |
| Groq 金鑰 | 免費申請，用來翻譯（下面步驟 4 會教你） |
| 網路 | 需要（下載影片聲音、翻譯） |

## 使用步驟

### 步驟 1：安裝 Python（已經裝過可以跳過）

**不確定有沒有裝過？** 按鍵盤的 `Windows 鍵`，輸入 `cmd` 按 Enter，在黑色視窗輸入 `python --version` 按 Enter：出現「Python 3.10」以上的數字就是裝過了，可以跳到步驟 2；出現其他訊息或跳出 Microsoft Store，就照下面安裝。

1. **[按這裡下載 Python 3.12 安裝檔（python-3.12.0-amd64.exe，約 25 MB）](../../releases/download/v1.2.1/python-3.12.0-amd64.exe)**。這是 Python 官方的安裝檔，原封不動放在這裡方便下載；也可以到官方網站 <https://www.python.org/downloads/windows/> 自己找「Python 3.12」的「Windows installer (64-bit)」。
2. 雙擊下載好的 `python-3.12.0-amd64.exe`。如果跳出「是否允許此應用程式變更你的裝置」，按「是」。
3. 安裝畫面出現後，**先把最下面的「Add python.exe to PATH」打勾**（沒勾的話之後會找不到 Python），再按上面的「**Install Now**」。
4. 等進度條跑完，出現「Setup was successful」後按「Close」。

### 步驟 2：安裝並啟動本機助手

1. 打開剛剛解壓縮的資料夾，雙擊 **`start-helper.bat`**。
2. 第一次會自動安裝需要的元件並下載語音模型（約 3 GB），大約需要 5～30 分鐘，看網路速度而定。過程中黑色視窗會一直跑文字，等它顯示「安裝完成！」。
3. 完成後，螢幕右下角的系統匣（時間旁邊的小圖示區，可能要按「^」才看得到）會出現紅色的「T」字樣圖示，代表本機助手正在背景執行。

> 之後每次要用，只要再雙擊一次 `start-helper.bat`，或在影片上按提醒卡片的「立即開啟」即可。也可以在設定頁打開「開機時自動啟動本機助手」。

### 步驟 3：把擴充功能裝進 Chrome

1. 在 Chrome 網址列輸入 `chrome://extensions` 後按 Enter。
2. 打開右上角的「**開發人員模式**」開關。
3. 按左上角的「**載入未封裝項目**」，選擇解壓縮資料夾裡的 **`extension`** 資料夾，按「選擇資料夾」。
4. 列表中出現「YT 字幕翻譯」就成功了。建議按 Chrome 右上角的拼圖圖示，把它釘選在工具列上。

> 使用 Edge 的話，網址改成 `edge://extensions`，打開左邊的「開發人員模式」，其他步驟一樣。

### 步驟 4：設定 Groq 金鑰（用來翻譯）

1. 打開 <https://console.groq.com/keys>，用 Google 帳號或信箱登入（免費）。
2. 按「Create API Key」，名稱隨便取，按「Submit」，複製畫面上那串 `gsk_` 開頭的金鑰。
3. 在 Chrome 工具列按「YT 字幕翻譯」圖示 →「設定」。
4. 在「Groq 金鑰」欄位貼上，按「儲存金鑰」，看到「金鑰已加密儲存」就完成了。

### 步驟 5：開始看影片

打開任何一部外國 YouTube 影片，幾秒後畫面下方就會出現翻譯字幕。播放器左上角會顯示目前狀態（例如「辨識中 35%」、「字幕已就緒」）。

- 播放器下方控制列右側的「**中**」按鈕：開關字幕。
- 影片右側（推薦影片上方）的面板：
  - 「**字幕**」分頁：整部影片的字幕與時間，目前播放的句子會標亮；點任何一句就跳到那裡。按「複製全部」可以複製整份字幕，滑鼠移到單句上也有複製鈕。自己往上下捲動時會暫停自動捲動，按「回到目前播放位置」就能回來。
  - 「**大綱**」分頁：等播放器上的字幕翻譯完成後，按「產生大綱」，就會整理成幾個段落（時間、小標題、重點）。點時間就跳到那一段。
  - 按右上角的「▾」可以收合面板。
- 設定頁可以調整：翻譯成哪種語言、影片說的語言、字幕位置、底色深淺、提醒時機、快取保留天數。

## 檔案說明

| 檔案／資料夾 | 用途 |
|---|---|
| `start-helper.bat` | 安裝（第一次）並啟動本機助手 |
| `extension\` | Chrome 擴充功能，步驟 3 要選的就是這個資料夾 |
| `extension\panel.css` | 影片右側「字幕／大綱」面板的外觀 |
| `helper\` | 本機助手的程式 |
| `helper\server.py` | 本機助手主程式（在背景執行，只接受這台電腦上的擴充功能呼叫） |
| `helper\transcribe.py` | 下載影片聲音並辨識成文字 |
| `helper\translate.py` | 用 Groq 翻譯字幕、整理大綱 |
| `helper\launcher.py` | 讓擴充功能的「立即開啟」按鈕能啟動本機助手 |
| `helper\requirements.txt` | 需要安裝的 Python 套件清單 |

## 常見問題

**Q：雙擊 start-helper.bat 後說「找不到 Python」？**
A：請照步驟 1 安裝 Python，安裝時一定要勾選「Add python.exe to PATH」。裝好後重新雙擊 `start-helper.bat`。

**Q：安裝到一半失敗或網路斷掉？**
A：重新雙擊 `start-helper.bat` 就會從中斷的地方繼續。

**Q：下載語音模型時，黑色視窗好像卡住不動？**
A：語音模型有 1.5～3 GB，視窗會每 3 秒顯示一次「已下載 ○○ MB」，數字有在增加就是正常在下載，請耐心等候。如果視窗標題前面出現「選取」兩個字，代表不小心點到視窗而暫停了，按一下 `Esc` 或 `Enter` 就會繼續。網路斷掉時會自動重試；真的失敗的話，重新雙擊 `start-helper.bat` 會從中斷的地方接著下載。

**Q：Windows 跳出藍色視窗「Windows 已保護您的電腦」？**
A：這是 Windows 對網路下載的檔案的一般提醒。按「其他資訊」→「仍要執行」即可。防毒軟體若擋下 `start-helper.bat`，請將資料夾設為允許。

**Q：我沒有 NVIDIA 顯示卡可以用嗎？**
A：可以。程式會自動改用 CPU 辨識，只是沒有字幕的影片要等比較久（大約是影片長度的一半到一倍時間）。有 CC 字幕的影片不受影響。

**Q：按「立即開啟」沒反應，叫我去雙擊 start-helper.bat？**
A：「立即開啟」要先執行過一次 `start-helper.bat` 才能用。**如果你搬動或改名了資料夾**，也要重新雙擊一次 `start-helper.bat`。

**Q：字幕一直顯示「尚未設定 Groq 金鑰」？**
A：請照步驟 4 設定金鑰。設定頁要在本機助手執行中才能修改。

**Q：出現「Groq 速率限制」？**
A：Groq 免費額度每分鐘有上限，程式會自動等待並改用其他模型，稍等一下就會繼續。

**Q：出現「Groq 拒絕目前的網路連線（403）」？**
A：通常是開了 VPN 或在公司網路。請先關掉 VPN 再試。公司網路需要 Proxy 時，請在 Windows 的環境變數設定 `HTTPS_PROXY`（請公司 IT 協助），然後重新啟動本機助手。

**Q：影片上出現「本機助手需要更新」？或大綱顯示「not found」？**
A：你更新了擴充功能，但電腦上還在跑舊版的本機助手。按卡片上的「立即重新啟動」（或大綱分頁的「重新啟動本機助手」）即可；如果沒有成功，在系統匣的紅色「T」圖示上按右鍵 →「結束」，再雙擊 `start-helper.bat`。

**Q：「產生大綱」按鈕是灰的？**
A：要等播放器上的字幕翻譯完成才能按，因為大綱和翻譯共用 Groq 的免費額度，先讓字幕出來。另外也需要本機助手執行中、並設定好 Groq 金鑰。

**Q：資料夾路徑有中文或空白可以嗎？**
A：可以。

**Q：哪些影片不能用？**
A：直播（有 CC 的直播可以用 YouTube 內建翻譯）、會員限定、私人影片、需要登入或有年齡限制的影片，本機助手下載不到聲音，會在畫面上顯示原因。

**Q：換了一台電腦／重灌後，金鑰不見了？**
A：金鑰是用 Windows 的加密功能存的，只有原本那台電腦、那個 Windows 帳號解得開，換電腦後請重新輸入一次。

**Q：字幕突然都不出現了？**
A：先重新整理 YouTube 頁面。YouTube 偶爾改版，本機助手每 3 天會自動更新下載工具；若還是不行，請到 GitHub 下載新版。

**Q：怎麼移除？**
A：1) 在設定頁關掉「開機時自動啟動本機助手」；2) 在系統匣的紅色「T」圖示上按右鍵 →「結束」；3) 到 `chrome://extensions` 移除「YT 字幕翻譯」；4) 刪除整個資料夾。

## 注意事項

**資料存在哪裡**（都在解壓縮的資料夾裡，不會存到其他地方）：

- `helper\config.json`：設定與 Groq 金鑰（金鑰有加密，只有這台電腦的這個帳號解得開）。
- `helper\cache\`：看過的影片字幕與大綱，預設保留 30 天後自動刪除，可在設定頁改天數或一鍵清除。
- `helper\helper.log`：執行紀錄（會記錄影片代碼），跟快取一樣到期自動刪除舊的內容。
- 分享這個資料夾給別人前，請先刪掉上面這三樣。

**會連到哪些網路服務**：

| 服務 | 送出什麼 | 什麼時候 |
|---|---|---|
| YouTube | 下載影片的聲音 | 影片沒有字幕、需要辨識時 |
| Groq（console.groq.com） | **只有字幕文字**與影片標題，聲音不會上傳 | 翻譯時、按「產生大綱」時 |
| Python 套件官方網站（PyPI） | 下載程式元件 | 第一次安裝時；之後每 3 天自動更新一次下載工具 |
| Hugging Face | 下載語音模型 | 第一次安裝時 |

- 語音辨識完全在你的電腦上進行，下載的聲音辨識完就自動刪除。
- 擴充功能只會連到你自己電腦上的本機助手（127.0.0.1），而且每次都要附上通行碼，其他網頁無法使用。
- 不需要系統管理員權限；「立即開啟」功能只會在目前使用者的登錄機碼裡登記啟動器的位置。
